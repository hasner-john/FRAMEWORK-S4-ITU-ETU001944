Sprint 8 - Upload de fichier

Objectif
Recevoir un fichier depuis un formulaire multipart, le rendre disponible dans une methode de controleur et le sauvegarder dans un dossier configure par l'application.

Implementation
- MaFile contient le nom, le type MIME, l'extension, les octets et le chemin de stockage.
- UploadManager lit les Part Servlet, construit MaFile et sauvegarde le fichier.
- Le dossier est configure avec le context-param uploadDirectory dans TEST/src/main/webapp/web.xml.
- Une methode de controleur peut recevoir directement MaFile fichier.
- Le formulaire doit utiliser enctype="multipart/form-data" et le nom du champ doit correspondre au nom du parametre Java.

Test
GET /upload-form affiche le formulaire.
POST /upload-save transmet le fichier au framework et affiche ses informations.
